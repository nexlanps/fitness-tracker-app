# Fitness Tracker App

Eine Full-Stack Fitness-Tracking-Anwendung mit Desktop- und Android-Support.

## Funktionen

- 📅 Kalenderansicht für Trainingstage, Messtage und Hauptmahlzeiten
- 📊 Grafische Darstellung der Messdaten (Gewicht, Körperfett, Bauchumfang, BMI)
- 💪 Trainingsplanung mit Details zu Übungen, Sätzen und Wiederholungen
- 🖥️ Desktop-Anwendung (Electron)
- 📱 Android-App (Ionic Capacitor)

## Tech-Stack

### Backend
- Python 3.x
- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic

### Frontend
- Angular
- Angular Material
- FullCalendar
- Chart.js

### Deployment
- Docker
- Nginx

## Projektstruktur

```
fitness-tracker/
├── backend/       # Python FastAPI Backend
├── frontend/      # Angular Web-App
├── desktop/       # Electron Desktop-App
├── mobile/        # Ionic Capacitor Android-App
└── docs/          # Dokumentation
```
